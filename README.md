# architectureastruth.com

This repository serves `architectureastruth.com` from GitHub Pages, and every page of it sends the reader to the same path on **https://architectureastruth.org/**, the reference site for Architecture as Truth (AAT).

The `.com` is held so that nobody else can hold it. The site, the wording and the kit are in [puglieseweb-personal/architecture-as-truth](https://github.com/puglieseweb-personal/architecture-as-truth).

Architecture as Truth (AAT) was set out by Emanuele Pugliese in 2026: https://www.puglieseweb.com/blog/architecture-as-truth
